## 📋 99条UX规范 (精选)

### 通用规范
1. **对比度** - 正文最低4.5:1，大文本3:1
2. **字体大小** - 正文最小16px，移动端18px
3. **触摸目标** - 最小44x44px
4. **焦点状态** - 可见焦点环(3-4px)
5. **键盘导航** - 所有交互元素可键盘访问
6. **屏幕阅读器** - 语义HTML + ARIA标签
7. **减少动效** - 尊重prefers-reduced-motion
8. **响应式** - 375px, 768px, 1024px, 1440px

### 动效规范
1. **微交互** - 50-100ms
2. **悬停状态** - 150-300ms
3. **页面过渡** - 300-400ms
4. **复杂动画** - 400-600ms
5. **缓动曲线** - cubic-bezier(0.4, 0, 0.2, 1)

### 布局规范
1. **网格** - 12列网格系统
2. **间距** - 8px倍数系统
3. **最大宽度** - 内容区1200-1440px
4. **边距** - 移动端16px，桌面端24-32px

## 🔧 设计系统生成工作流

### Step 1: 分析需求
```bash
# 提取关键信息
- 产品类型：[SaaS/电商/医疗/...]
- 目标受众：[B2B/B2C/...]
- 风格关键词：[现代/极简/活泼/...]
- 技术栈：[React/Next.js/Vue/...]
```

### Step 2: 生成设计系统
```bash
# 使用搜索脚本
python3 skills/ui-ux-pro-max/scripts/search.py "<product_type> <industry> <keywords>" --design-system -p "Project Name"
```

### Step 3: 应用设计规则
```
1. 选择UI风格 → 参考67种风格表
2. 确定配色方案 → 参考161套配色表
3. 选择字体配对 → 参考57种字体表
4. 应用UX规范 → 参考99条UX规范
```

### Step 4: 交付前检查
```
□ 无emoji作为图标 (使用SVG: Heroicons/Lucide)
□ 所有可点击元素有cursor-pointer
□ 悬停状态平滑过渡 (150-300ms)
□ 浅色模式文本对比度4.5:1+
□ 焦点状态对键盘导航可见
□ 尊重prefers-reduced-motion
□ 响应式：375px, 768px, 1024px, 1440px
□ 加载状态(骨骼屏)已实现
□ 空状态已实现
□ 错误状态已实现
□ 触摸目标44x44px
□ 语义HTML + ARIA标签
```

## 🚫 通用反模式 (必须避免)

### 视觉反模式
- ❌ AI紫色/蓝色霓虹美学
- ❌ Emoji作为图标
- ❌ 过度渐变和阴影
- ❌ 默认Inter字体(创意场景)
- ❌ 居中Hero(LAYOUT_VARIANCE>4时)

### 交互反模式
- ❌ 无悬停状态
- ❌ 无焦点状态
- ❌ 无加载状态
- ❌ 无空状态
- ❌ 无错误状态

### 布局反模式
- ❌ h-screen (使用min-h-[100dvh])
- ❌ 复杂flex百分比数学 (使用CSS Grid)
- ❌ 假设库存在 (检查package.json)
