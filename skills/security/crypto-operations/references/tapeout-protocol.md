## 核心机制

### Token层级
- **晶体管 (Transistor)**: ERC-1155 Token，分为NAND门和LATCH触发器
- **电路 (Circuit)**: ERC-721 NFT，由晶体管"流片"（销毁Token）生成
- **处理器 (CPU)**: 由电路拼装，每个处理器是独立ERC-721合约

### 工作原理
1. 晶体管 = 最小计算元件（与非门NAND + 触发器LATCH）
2. 晶体管在画布系统中连线 → 点"流片" → 销毁Token，生成电路NFT
3. 电路可当黑盒拼装进更大电路
4. 最终组装成完整CPU，时钟 = BNB Chain出块速度（0.45秒/拍，2.22Hz）

### 已有产品
- **巨兽 Behemoth**: 对标1971年Intel 4004的链上CPU，2251个逻辑门
- **链上BTC矿机**: SHA-256电路在链上跑PoW挖矿（技术Demo，算力极低）

## 链上BTC矿机可行性分析

### 技术上可行
- SHA-256电路已在BNB链上部署并运行
- 任何人可免费调用（只读查询，不花Gas）

### 实际不可行
- 时钟频率2.22Hz（每0.45秒一个周期）
- 真正BTC矿机算力是TH/s级别
- 差距约15个数量级
- 本质上是技术概念验证，不是挖矿工具
