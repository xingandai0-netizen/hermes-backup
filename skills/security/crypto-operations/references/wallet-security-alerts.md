# 钱包安全警报汇总

## imToken Chrome插件钓鱼事件 (2026年2-3月)

### 事件概要
- 2026年2月2日，恶意Chrome插件发布到Chrome Web Store
- 插件名为"lm-token-chromophore"，伪装成hex颜色可视化工具
- 实际功能：安装后自动打开钓鱼网站，窃取助记词和私钥
- 插件使用仿冒的品牌图片、假五星评论、假隐私政策

### 钓鱼流程
1. 安装插件 → 自动打开钓鱼站
2. 钓鱼站模仿imToken界面
3. 要求输入12/24位助记词或明文私钥
4. 导入后打开真正的token.im网站（让用户以为是真的）
5. 攻击者已获取钱包控制权

### 官方确认
- imToken官方声明：仅提供手机App，从未发布Chrome浏览器插件
- SlowMist（慢雾安全团队）2026年3月6日发出安全警报
- Socket Threat Research Team 2026年2月发现并报告

### 教训
- 任何声称是钱包的浏览器插件都要高度警惕
- 只从官方App Store/Google Play下载钱包
- 永远不要在浏览器插件中输入助记词
- 公开地址可以查余额，但不会泄露资产

## 通用钱包安全建议
- 助记词手写保存，不截图、不存云端
- 大额资产用硬件钱包（Ledger/Trezor）
- 交易前核实合约地址
- 定期检查授权的合约权限
