## 使用方式

```
# 写PRD
"帮我写一个通知偏好功能的PRD，做合理假设并标注"

# 分析SaaS指标
"分析这些指标：MRR $50k, 500客户, 毛利率80%, 月流失8%, CAC $500"

# 竞品分析
"帮我做竞品分析，对标TapNow和Canva"

# 路线图规划
"审查我的路线图，找出利益相关者请求超过证据的地方"
```

## 关键Pitfall

- **不是模板包** — 每个skill都有教学内容，帮PM理解"为什么"
- **反模式是核心** — 教你识别"方案走私"、"指标剧场"、"功能工厂"
- **输入灵活** — 可以带完整上下文，也可以空手来，引导流程覆盖缺失部分
