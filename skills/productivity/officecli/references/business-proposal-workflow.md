# 企划书制作工作流

## Phase 1: 资料收集（必须先做）

**问用户要以下信息（一次性问完）：**
1. 公司/项目名称 + Logo
2. 一句话定位（做什么，给谁用）
3. 联系方式 + 融资轮次
4. 痛点场景（越具体越好，要真实场景）
5. 解决方案（产品/服务 + 核心功能）
6. 商业模式（怎么赚钱 + 定价）
7. 牵引力（进展阶段 + 用户数据）
8. 竞品（3-5个 + 核心优势）
9. 团队（成员背景 + 为什么是你）
10. 财务（成本 + 收入预期）
11. 融资需求（金额 + 用途 + 出让比例）

**用户给不出的，主动调研：**
- 市场规模（用web_search查行业报告）
- 竞品定价（直接访问竞品官网pricing页）
- 行业数据（CAGR、用户数、营收等）

## Phase 2: 市场调研

**调研方法：**
```bash
# 搜索行业数据
web_search("行业名 市场规模 2025 2026")
# 访问竞品定价页
web_extract(["https://competitor.com/pricing"])
```

**常见赛道竞品参考：**
- 画布/创作工具：SeedDance, TapNow, 即梦AI, Lovart
- 玄学/命理：测测(6000万用户), 灵机妙算, 同道大叔(估值2亿)

## Phase 3: 制作PPT

**格式决策：**
| 场景 | 格式 |
|------|------|
| 发给投资人 | PPTX（用officecli） |
| 需要视觉冲击 | HTML（用frontend-slides） |
| 团队内部编辑 | PPTX |

**PPTX制作流程：**
1. `officecli create bp.pptx`
2. 逐页添加slide + shape
3. `officecli view bp.pptx outline` 验证
4. `officecli close bp.pptx` 保存

**设计规范：**
- 深色背景（#0A0A1A）+ 科技蓝强调色（#4FC3F7）
- 金色用于差异化产品（#FFD54F）
- 标题32px，正文14-16px
- 每页信息点不超过3个

## Phase 4: 验证

- 用PowerPoint打开检查排版
- 确认所有文字可读
- 检查数据准确性
- 文件名：「公司名-融资轮次-日期-BP.pptx」
