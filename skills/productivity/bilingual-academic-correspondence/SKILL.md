# Bilingual Academic & Institutional Correspondence

## When to Use

- Writing to universities, professors, or institutions in **Singapore, UK, Hong Kong, or other English-official contexts**
- User communicates in Chinese but recipient requires English (or bilingual)
- Formal requests: leave of absence, enrollment changes, medical certificates, appeals

## Key Rule: Always Ask About Bilingual Requirement

If user asks you to write **only in Chinese** for an international context, **proactively ask** if bilingual format is needed. Many institutions (especially Singapore and UK) require English as the official language.

**Template prompt:** "这封邮件是发给哪里的？如果对方是新加坡/英国的机构，通常需要中英双语。要我写成双语版吗？"

## Bilingual Email Format

### Structure (每段中英对照)

```
Subject: [English subject line]

Dear [Title] [Family Name],

[Chinese paragraph 1]
[English translation of paragraph 1]

[Chinese paragraph 2]
[English translation of paragraph 2]

[Closing in Chinese]
[Closing in English]

Best regards,

[Chinese Name] [English Name]
Student ID / ID: [...]
Email: [...]
Phone: [country code + number]
```

### Rules
1. **Each Chinese paragraph is immediately followed by its English translation** — don't cluster all Chinese then all English
2. **Formal register** in both languages — no colloquial Chinese, no casual English
3. **Subject line in English** — email systems and staff expect English subjects
4. **Signature includes both names** — Chinese name first, English name in parentheses or after
5. **Phone number with country code** — e.g., +86 138xxxx or +65 9xxx xxxx

## Common Scenarios

### 1. Leave of Absence (休学申请)

```
Subject: Leave of Absence Request — [Programme Name]

Dear [Title] [Name],

我是您的学生[中文名]（学号：[学号]），课程：[Programme]。由于[家庭/个人/健康]原因，我需要申请暂时休学。

I am your student [English Name] (Student ID: [ID]), enrolled in [Programme]. Due to [family/personal/health] reasons, I am writing to request a temporary leave of absence.

[详细说明 / Detailed explanation]

[请教事项 / Enquiry items]:
1. 办理休学的具体流程和所需材料
   The specific process and required documents for filing a leave of absence.
2. 当前课程如何处理
   How the current coursework will be handled.
3. 休学期间需要注意的事项
   Any matters to be aware of during the leave period.

给您带来的不便深表歉意，希望能得到您的理解与支持。
I sincerely apologise for any inconvenience and hope for your understanding and support.

Best regards,
[中文名] [English Name]
```

### 2. Medical Refund Request (医疗退票申请)

```
Subject: Medical Refund Request — [Booking Reference]

Dear [Airline/Company] Team,

[说明情况 / Statement of circumstances]
[English translation]

[医疗证明 / Medical documentation reference]
[English translation]

[具体请求 / Specific request]
[English translation]

Best regards,
[Name]
```

### 3. Rental Contract Inquiry (租房合同咨询)

```
Subject: Tenancy Agreement [Reference] — [Brief Description]

Dear [Company] Team,

[说明情况]
[English translation]

[具体问题列表 / Numbered questions]
1. [Chinese] / [English]
2. [Chinese] / [English]

Best regards,
[Name]
Identity No.: [...]
```

## Pitfalls

1. **Don't assume Chinese-only is OK** — Even if user writes in Chinese, international institutions often require English. Always confirm.

2. **Singapore specific:** Official languages are English, Chinese, Malay, Tamil. But institutional/business communication is primarily in English. Bilingual is polite but English is mandatory.

3. **UK specific:** English only is standard. Bilingual is unusual and may seem odd. Only use bilingual if user specifically requests it or if the institution is known to accept Chinese.

4. **Academic titles matter:** Use "Dr", "Professor" correctly. In Singapore, "Dr" is common for PhD holders who are not yet full professors. Check the person's actual title.

5. **Formal vs informal Chinese:** Use 您 not 你 for professors and officials. Use 此致敬礼 or Best regards — not 祝好 or Cheers.

6. **Student ID format:** Different schools have different formats (numeric, alphanumeric). Always include it in the signature for identification.

## Quick Reference

| Context | Language | Format |
|---------|----------|--------|
| Singapore university | Bilingual (CN+EN) | Each paragraph bilingual |
| UK university | English primary | English only unless requested |
| Hong Kong university | Bilingual (CN+EN) | Each paragraph bilingual |
| Singapore company | English primary | English, bilingual if asked |
| Chinese institution | Chinese | Chinese only |
