# 本次会话中的典型错误案例

## 案例1：删除重复条目时误删其他内容
**场景**：NodePanel.tsx中有重复的img2video条目，需要删除重复
**错误**：使用大块文本替换，导致videoComposite也被删除
**正确做法**：逐行检查，只删除重复的行，保留其他内容

## 案例2：修改只改一处，没改其他相关地方
**场景**：给节点添加尺寸选择功能
**错误**：只给ImageGenNode和VideoGenNode添加，没给输出区的3个节点添加
**用户反馈**："做事做一半"
**正确做法**：列出所有需要修改的节点，一次性全部改完

## 案例3：没理解API逻辑就动手写代码
**场景**：实现图片合成功能
**错误**：直接把URL拼接到prompt里，没看API文档
**结果**：API不支持直接URL，需要先上传到asset系统
**正确做法**：先阅读API文档，理解参数格式，再写代码

## 案例4：修改后没验证完整性
**场景**：修复Handle重复问题
**错误**：删除手动Handle后没检查是否有遗漏
**结果**：有些节点的Handle被删了但没加回来
**正确做法**：修改后重新读取文件，验证所有内容完整
