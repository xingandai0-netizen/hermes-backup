# 商用 AI 画布产品构建路线图
**日期**: 2026-06-29

## 一、TapNow 构建过程还原

### 公司背景
- **母公司**: PressLogic（香港广告科技集团，2016年成立，200+员工，9个媒体品牌）
- **TapNow 独立实体**: 注册在美国特拉华州，办公室在香港
- **创始人**: Jessie Qin（复旦15岁入学，伦敦商学院硕士，前UBS投行副总监，2023年1月创办）
- **联合创始人**: Klaus He
- **团队**: ~29人（LinkedIn数据）

### 融资
- **Series A**: 2023年10月，约$1.94M
- **投资方**: SBI Investment（日本）、DIMENSION（日本）
- **母公司支持**: PressLogic 2018年获美图$10M A+轮

### 时间线
```

2023.10  Series A 融资 $1.94M（SBI + DIMENSION）

2025.09  正式商业发布
2025秋   TapNow Manifesto 发布
2026.03  SXSW 发布 TapNow 2.0 + "Agentic Canvas" 概念
2026.04  Soulscape AI Cinema Summit
2026.06  Seedance 2.0 (4K) 集成
2026.07  "10,000 Parallel Universes" 全球创意大赛（$400K奖金池）
```

### 商业成绩
- **发布4个月内达到 $20M ARR**（Jessie Qin LinkedIn数据）
- **企业客户**: 阿里巴巴、Google Ads、TikTok、YouTube、字节跳动、腾讯、WPP、Honda

### 技术架构
- **核心**: 节点式无限画布，每个节点是原子创意操作
- **AI Agent**: "Executive Director" Agent 编排多步创意工作流
- **模型集成**: 35+ 第三方模型（非自研，API聚合）
- **后端**: Python/Node.js/Go，RAG路由，低延迟API集成
- **成本优化**: prompt caching、token优化

### 竞争定位
- vs Krea: 更多模型(35+ vs 15+)，更便宜($9 vs $10)
- vs Runway: 多厂商聚合 vs 单厂商自研
- 核心差异化: 节点画布 + 多模型编排 + AI Agent + 影视级摄像机模拟

## 三、产品构建六阶段

### Phase 1: 验证期（1-3个月）
**目标**: 验证需求，找到PMF切入点

| 任务 | 产出 |
|------|------|
| 竞品分析 | 竞品功能矩阵、定价对比、用户评价 |
| 用户调研 | 目标用户画像、痛点清单 |
| 技术选型 | 画布引擎、后端架构、模型集成方案 |
| MVP定义 | 核心功能列表（不超过3个） |

**关键决策**:
- 模型策略：API聚合（快，低风险）vs 自研（高壁垒，高成本）
- 目标用户：创作者（TapNow）vs 开发者（Dify）vs 企业（Runway）
- 画布类型：节点式工作流 vs 自由画布 vs 混合

**预算**: $10K-$50K（自筹）

### Phase 2: MVP期（3-6个月）
**目标**: 最小可用产品，验证核心价值

| 任务 | 技术栈 |
|------|--------|
| 画布引擎 | React Flow（节点式）或 Konva.js/Fabric.js（自由画布） |
| 后端API | FastAPI + Redis队列 + Celery异步任务 |
| 模型集成 | 2-3个核心模型（如Gemini图片+Seedance视频+一个文本模型） |
| 用户系统 | Supabase Auth（GitHub+邮箱） |
| 存储 | Supabase Storage + PostgreSQL |
| 部署 | Vercel(前端) + Railway/Fly.io(后端) |

**核心功能**（不超过3个）:
1. 无限画布 + 节点创建/连接
2. 一个核心生成能力（图片或视频）
3. 基础用户系统（登录/注册/项目保存）

**团队**: 2-3人（1全栈+1前端+1后端/ML）
**预算**: $50K-$200K

### Phase 3: 产品化（3-6个月）
**目标**: 完善产品体验，开始变现

| 任务 | 说明 |
|------|------|
| 多模型集成 | 5-10个模型，动态发现 |
| 付费系统 | Stripe（订阅+积分制） |
| 项目管理 | 多项目、云端保存、历史版本 |
| 协作功能 | 分享链接、只读视图 |
| 内容审核 | 输入prompt过滤 + 输出图片分类 |
| 移动端适配 | 响应式设计 |

**定价模型参考**:
```
Free    — 100积分/月，基础模型
Basic   — $9/月，1000积分，全模型
Pro     — $29/月，5000积分，优先队列
Enterprise — 定制，API访问，SSO
```

**团队**: 5-8人
**预算**: $200K-$500K

### Phase 4: 增长期（6-12个月）
**目标**: 获取用户，验证商业模式

| 任务 | 策略 |
|------|------|
| Product Hunt 发布 | 周一上线，提前2-4周预热 |
| 社区建设 | Discord + Twitter/X + Reddit |
| 内容营销 | 教程视频、模板库、案例展示 |
| SEO | 博客+工具页+对比页 |
| 创作者计划 | 邀请KOL试用，TapTV式工作流分享 |
| hackathon | 线上线下创意比赛 |

**关键指标**:
- MAU（月活跃用户）
- 付费转化率（目标5-10%）
- 留存率（D7 > 40%, D30 > 20%）
- ARPU（每用户平均收入）

**团队**: 10-15人（+2增长+2社区）
**预算**: $500K-$2M

### Phase 5: 规模化（12-24个月）
**目标**: 扩大规模，建立壁垒

| 任务 | 说明 |
|------|------|
| 自研模型 | 微调专属模型，降低成本，建立壁垒 |
| GPU基础设施 | 自建推理集群或长期合约云GPU |
| 企业功能 | SSO、RBAC、审计日志、SLA |
| API开放 | 开发者API、SDK、Webhook |
| 国际化 | 多语言、本地化支付 |
| SOC2合规 | 企业客户必备 |

**关键决策**:
- 自建GPU vs 云GPU（日生成>5万次时自建更划算）
- 自研模型 vs 继续聚合（自研=壁垒，聚合=速度）

**团队**: 20-30人
**融资**: Series A $5-15M
**预算**: $2M-$10M

### Phase 6: 生态化（24个月+）
**目标**: 构建平台生态

| 任务 | 说明 |
|------|------|
| 插件市场 | 第三方模型/节点/模板 |
| 工作流市场 | 用户创建的工作流可售卖 |
| 教育体系 | 认证课程、创作者社区 |
| 垂直行业 | 影视、电商、广告、教育定制方案 |

## 四、Antoken 对标建议

### 当前阶段: Phase 1→2 过渡期
Antoken 已有：
- ✅ 无限画布（React Flow）
- ✅ 多模型集成（toapis.com）
- ✅ 节点式工作流
- ✅ 基础用户系统（Supabase Auth）
- ✅ 部署架构（Vercel + Railway）

Antoken 缺少：
- ❌ 云端项目保存（用户数据持久化）
- ❌ 付费系统
- ❌ 内容审核
- ❌ 生产级基础设施
- ❌ 法律合规（ToS、隐私政策）

### 建议路径
```
当前 → 补全云端存储 → 产品化(付费) → Product Hunt上线 → 增长
```

### 核心优势（vs TapNow）
1. **开源可控** — 代码完全自控，不受平台限制
2. **成本低** — 无29人团队开销，AI辅助开发
3. **灵活** — 可快速调整方向
4. **已有基础** — 画布+模型集成+Auth已就绪

### 核心劣势（vs TapNow）
1. **无融资** — TapNow有$1.94M+母公司支持
2. **无影视级工具** — TapNow的摄像机/灯光模拟是核心壁垒
3. **无社区** — TapNow有TapTV工作流分享社区
4. **模型数量** — TapNow 35+ vs Antoken ~10

## 三、功能策略分层（阿戴确认）

**与竞品持平即可（稳定没bug）**：
- API Key管理、登录体验、使用仪表盘、后端架构
- 这些功能不需要创新，需要稳定可靠

**超越竞品的差异化点（重点投入）**：
- 版本历史+回滚、项目导出/导入JSON、开发者API
- 简洁定价（3档vs竞品6档）、完整快捷键系统

**不追的领域（实事求是）**：
- 专业影视工具（需要行业知识）
- AI Agent全局画布理解（需要大量研发）
- 模型数量（依赖第三方API）

## 四、关键成功因素

1. **速度** — Krea从idea到$500M估值只用了3年
2. **社区** — Discord/Twitter社区是免费增长引擎
3. **模型无关** — 聚合最佳模型比自研更快上线
4. **用户体验** — 简洁>复杂（Midjourney靠Discord+简单UX成功）
5. **现金流** — GPU成本是最大开支，架构效率决定生死
6. **法律合规** — 内容审核+ToS+版权是商用必需
