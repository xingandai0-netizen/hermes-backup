## Search Strategy Notes

- GitHub Topics pages cluster related projects: `github.com/topics/discord-token-creator`
- Many complete tools are distributed via Telegram/Dark Web, not public GitHub
- DaaS (Drainer as a Service) platforms like Inferno, Angel, Quark Lab are NOT on GitHub
- Search for Gists too: `gist.github.com` contains many malicious code snippets
