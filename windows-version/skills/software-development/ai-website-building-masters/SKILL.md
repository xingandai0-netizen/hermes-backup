## 🚨 关键教训：UI 复制规则（2026-07-03 新增）

**当用户说"用v1的UI"时，意思是：复制v1的代码，一模一样，不是"风格相似"。**

### 错误做法 ❌
- 看v1的设计风格，然后用shadcn/ui重新实现一个"类似"的
- 说"已改为Apple Glass风格"但代码完全不同

### 正确做法 ✅
1. 直接 `cp` v1的组件文件到v2
2. 创建兼容层（stores、types、utils）让v1代码能运行
3. 修复导入路径（v1用的路径在v2可能不存在）
4. 验证构建通过

### v1→v2 迁移清单
```
1. 复制组件文件（cp 命令）
2. 创建v1兼容的Zustand stores（v1用Zustand，不是Jotai）
3. 创建v1兼容的类型定义（workflow-v1.ts）
4. 创建工具函数别名（api-base.ts, media-proxy.ts, asset-upload.ts）
5. 批量替换导入路径：
   - @/stores/workflowStore → @/stores/v1-compat
   - @/stores/settingsStore → @/stores/v1-compat
   - @/types/workflow → @/types/workflow-v1
   - @/lib/api → @/lib/api-base
   - @/lib/assetUpload → @/lib/asset-upload
   - @/lib/mediaProxy → @/lib/media-proxy
   - @/lib/constants → @/lib/constants-v1
   - ./BaseNode → ./base-node
   - @/components/PreviewModal → @/components/preview-modal
   - @/components/MentionInput → @/components/mention-input
6. 添加 eslint-disable 注释（v1代码可能有any类型）
7. 验证构建通过
```

## 🎨 UI 设计铁律（阿戴 2026-06-29 确认）

**绝对禁止**：AI 自己设计 UI（自己写 CSS、自己调样式）。AI 生成的 UI "AI味很重"，不专业。

**正确做法**：去 GitHub 找成熟的开源 UI 素材库，直接用。

### 推荐 UI 库组合

| 层级 | 库 | GitHub Stars | 用途 |
|------|-----|-------------|------|
| 核心组件 | shadcn/ui | 118k | 按钮/卡片/弹窗/输入框/侧边栏 |
| 动效组件 | Magic UI | 21k | 光效边框/Bento网格/动画背景 |
| 文字动画 | React Bits | 42k | 模糊文字/闪烁效果/数字滚动 |
| 动画引擎 | Framer Motion | - | 共享动画库 |

### 安装方式

```bash
# 核心
npx shadcn@latest init
npx shadcn@latest add button card dialog input select badge tabs textarea

# 动效
npx shadcn@latest add "https://magicui.design/r/marquee"
npx shadcn@latest add "https://magicui.design/r/bento-grid"
```

### shadcn/ui + Tailwind v4 兼容性陷阱

shadcn/ui 4.x 强制依赖 Tailwind v4。如果项目用 Tailwind v3 会报错。

```bash
# 必须升级
npm install tailwindcss@4 @tailwindcss/postcss
```

PostCSS 配置改为：
```js
// postcss.config.mjs
export default { plugins: { "@tailwindcss/postcss": {} } };
```

globals.css 中 `@apply border-border` 在 v4 不可用，改为直接 CSS：
```css
/* ❌ Tailwind v3 */
* { @apply border-border outline-ring/50; }
body { @apply bg-background text-foreground; }

/* ✅ Tailwind v4 */
* { border-color: var(--border); outline-color: var(--ring); }
body { background-color: var(--background); color: var(--foreground); }
```

详见 `references/shadcn-tailwind-v4-setup.md`

## 🔴 UI 复制规则（2026-07-03 新增）

**用户原话**："不是让你改回去风格，是要和之前未开始重构antoken项目前备份的所有ui一模一样。"

**规则**：当用户说"用v1的UI"或"和之前一样"时：
- ✅ 直接复制源代码文件
- ✅ 创建兼容层（stores、types、utils）
- ✅ 批量替换导入路径
- ❌ 不要"参考风格重写"
- ❌ 不要"保持一致的设计语言"
- ❌ 不要自己设计"类似的"组件

**原因**：AI 重写的 UI 即使"风格一致"，细节也会丢失（间距、动画、交互逻辑）。用户要的是零差异。
