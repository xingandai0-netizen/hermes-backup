# 迭代式UI精炼模式（已验证）

## 阿戴的UI调整模式

阿戴会反复要求UI调整，通常是简化和删除：

### 常见调整模式

1. **删除装饰性元素**
   - "这个删了" → 立即执行
   - 不要问为什么
   - 不要建议保留

2. **简化品牌元素**
   - 品牌名：小算一下 → 小算
   - 按钮：小算一下 → → 小算一下
   - 标签：东方命理，云海问卦 → 删除

3. **颜色和样式调整**
   - "字体颜色改成黑色"
   - "去除图表"（指地球图标）
   - "背景改成米白色"

4. **动画调整**
   - "把小道童扫地改成这个动画"
   - "只要人物，背景透明色"
   - "移除这个动画"

### 响应策略

**立即执行**：当用户说"删了"或"这个删了"
**不要问**：为什么删除、是否确认、建议保留
**不要解释**：删除的影响、技术细节

### 代码管理策略

**保留可回退状态**：
- 每次修改前先读取现有代码
- 使用git或手动备份
- 不要一次性删除所有相关代码

**系统性删除**：
- 删除useRef声明
- 删除useEffect调用
- 删除函数定义
- 删除import语句
- 检查是否还有引用

### 品牌命名最终状态

| 元素 | 最终值 | 历史变更 |
|------|--------|----------|
| Logo | 安 | 算 → 安 |
| 品牌名 | 小算 | 算了么 → 小算一下 → 小算 |
| 主按钮 | 小算一下 | 小算一下 → → 小算一下 |
| 次按钮 | 每日一签 | 🎋 每日一签 → 每日一签 |
| 标语 | 已删除 | 东方命理，云海问卦 → 删除 |

### 滚动渐变颜色系统

**所有元素都要随滚动变化**：
- 背景色：米白色 → 黑色
- 文字颜色：黑色 → 白色
- 按钮颜色：深色 → 浅色
- 卡片背景：白色 → 半透明
- 边框颜色：浅灰 → 半透明白色
- 图标颜色：深色 → 浅色

**不能遗漏**：
- 导航栏元素
- 语言选择器
- 按钮文字
- 卡片标题
- 卡片描述
- 页脚链接

**实现方式**：
```typescript
// 颜色辅助函数
const getTextColor = (progress: number, light: string, dark: string) => 
  progress > 0.5 ? light : dark

// 在组件外计算颜色变量
const textColor900 = getTextColor(scrollProgress, '#fff', '#111827')
const textColor500 = getTextColor(scrollProgress, 'rgba(255,255,255,0.6)', '#6b7280')

// 在JSX中使用
<h1 style={{ color: textColor900 }}>标题</h1>
<p style={{ color: textColor500 }}>正文</p>
```

**⚠️ Pitfall**：Tailwind的className（如`text-gray-900`）是静态的，不会随滚动变化。必须使用style属性。
