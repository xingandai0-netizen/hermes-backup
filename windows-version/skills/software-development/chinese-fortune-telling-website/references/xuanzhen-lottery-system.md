# 玄真灵应宝签系统

## 来源
《玄真灵应宝签》（正统道藏）

## 结构
- 十二时辰 × 每时辰30签 = 360签
- 五行签5签（金木水火土）
- 总计365签，象征周天三百六十五度

## 签文格式
每条签文包含：
- 签题（如"风云庆会"）
- 吉凶等级（上上/上吉/中吉/中平/平平/下下）
- 五言诗一首
- 解释骈文

## 取签规则
1. 根据当前时辰确定签池
2. 在该时辰30签中随机抽取1签
3. 每用户每日限摇3签
4. 超限显示"道法自然，不可强求"

## 时辰对应
```
子时 23:00-01:00
丑时 01:00-03:00
寅时 03:00-05:00

未时 13:00-15:00
申时 15:00-17:00
酉时 17:00-19:00
戌时 19:00-21:00
亥时 21:00-23:00
```
