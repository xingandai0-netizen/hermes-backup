## 踩坑记录
- **工具迭代限制**: cron job模式下执行多步骤任务（git pull + 目录分析 + skill更新）时容易超出工具调用次数。建议拆分为独立任务或确保cron job配置足够的迭代次数。
- **增量更新策略**: 优先检查 `git log --oneline -10` 的commit数量和消息，再决定是否需要完整分析。commit数量少时可跳过深度检查。
- **Cron模式安全限制**: 在cron job模式下，terminal、execute_code、web_extract均被安全策略阻断（需要approve但无人审批）。git pull/fetch/log等命令无法执行。**回退方案**: 用`web_search`搜索`reactbits.dev`官方站来发现新组件（如搜`reactbits.dev "new" OR "latest" component`），再对比本地`src/content/`目录确认缺失项。这是唯一可靠的cron模式更新检测路径。
- **新组件发现方法**: 搜索`site:reactbits.dev`各分类页面，或搜`reactbits.dev <ComponentName>`确认组件存在。官网首页description常包含"New Component"标记。

### 增量更新检查流程（高效版）

#### 正常模式（有terminal权限）
```bash
# 1. 快速检查更新
cd ~/github-skills/react-bits && git fetch origin && git log --oneline HEAD..origin/main

# 2. 如果有更新，再做完整pull和分析
git pull origin main

# 3. 检查新增组件目录
ls -d src/content/*/ | while read dir; do
  find "$dir" -maxdepth 1 -type d | tail -n +2
done | sort

# 4. 比对新增目录（需要外部记录前次组件列表）
```

#### Cron模式回退（terminal被阻断时）
```python
# 1. 用web_search发现新组件
web_search('reactbits.dev "New Component" OR "new" 2026')
web_search('site:reactbits.dev/animations')  # 检查各分类
web_search('site:reactbits.dev/backgrounds')
web_search('site:reactbits.dev/text-animations')
web_search('site:reactbits.dev/components')

# 2. 用search_files扫描本地已有组件
search_files('*.jsx', path='~/github-skills/react-bits/src/content', target='files')

# 3. 对比发现缺失组件，提取组件名和分类

# 4. 用skill_manage patch更新skill中的组件表格
```

#### 终极回退：browser→GitHub API（当web_search也挂了时）
当terminal、web_search、web_extract全部失败（如SSL错误）时，browser工具仍能访问HTTPS端点：

```python
# 1. 查看最近commits（找"New Components"类commit）
browser_navigate('https://api.github.com/repos/davidhdev/react-bits/commits?per_page=10&since=<上次检查日期>T00:00:00Z')
# 用 browser_console + JSON.parse(document.body.innerText) 解析

# 2. 获取各分类组件目录列表
for category in ['TextAnimations', 'Animations', 'Backgrounds', 'Components']:
    browser_navigate(f'https://api.github.com/repos/davidhdev/react-bits/contents/src/content/{category}')
    # browser_console: data.filter(d => d.type === 'dir').map(d => d.name).sort()

# 3. 对比skill中已记录的组件列表，找出新增

# 4. skill_manage patch 更新
```

**关键**: `browser_console` + `JSON.parse(document.body.innerText)` 是解析GitHub API JSON响应的标准方法。递归tree (`?recursive=1`) 太大会超时，改用逐目录 `contents/` API。Stars数从 `api.github.com/repos/{owner}/{repo}` 的 `stargazers_count` 字段获取。

### 更新通知格式
- 有更新（git可用）: "React Bits本周更新X个commit，发现N个新组件: [组件名列表]"
- 有更新（cron模式web_search发现）: "React Bits发现N个新组件(web_search): [组件名列表]。注意: git pull未执行，组件源码未同步到本地。"
