## 实战经验 (2026-04-17)

### 问题1: JSON解析失败
**症状**: prepare-digest.js输出包含控制字符，导致JSON解析失败
**原因**: 播客转录文本包含特殊字符
**解决方案**: 直接读取feed文件，而非通过prepare-digest.js
```python
import json, re
with open('~/follow-builders/feed-x.json', 'r') as f:
    content = f.read()
    content = re.sub(r'[\x00-\x1f\x7f]', ' ', content)
    data = json.loads(content[content.find('{'):content.rfind('}')+1])
```

### 问题2: 直接读取Feed文件
**文件路径**:
- `~/follow-builders/feed-x.json` - X/Twitter数据
- `~/follow-builders/feed-podcasts.json` - 播客数据
- `~/follow-builders/feed-blogs.json` - 博客数据

### 热门内容排序方法
```python
# 按点赞数排序推文
all_tweets = []
for builder in data['x']['x']:
    for tweet in builder.get('tweets', []):
        all_tweets.append({
            'name': builder['name'],
            'likes': tweet.get('likes', 0),
            'text': tweet['text'],
            'url': tweet['url']
        })
hot_tweets = sorted(all_tweets, key=lambda x: x['likes'], reverse=True)[:15]
```
